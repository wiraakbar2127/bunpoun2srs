Save & Sinkron

Progress disimpan otomatis di browser ini. Untuk memindahkan progress ke web/mobile lain, export save dari perangkat ini lalu import file save di perangkat tujuan.

File save berisi seluruh bunpou, status Yomimashita, level SRS setiap contoh kalimat, dan jadwal review.

Kesempatan kedua

Kamu berada di SRS Level 11. Kesalahan pertama belum menurunkan level. Kamu mendapat satu kesempatan lagi untuk soal yang sama.

Jika jawaban kedua juga salah, level turun ke 10 dan kartu kembali setelah 10 menit.
